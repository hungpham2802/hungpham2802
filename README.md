## 🛠️ SPClean — SharePoint Permission Hygiene Toolkit

> A PowerShell module for SharePoint Online admins who want clean, auditable tenants without paying enterprise-software prices.

**Module 1 (in development):** Orphaned user detection, risk scoring, HTML/CSV reporting, safe removal with snapshot backup.

```powershell
# Scan all sites, get a clean HTML report
Connect-SPCTenant -TenantName contoso.onmicrosoft.com
Get-SPCOrphanedUser -AllSites | Export-SPCReport -Format HTML -IncludeSummary
```
